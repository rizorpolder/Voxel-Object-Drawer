Это шаблон проекта под WebGL, где ставилась задача загрузки файла типа .vox в проект, создания воксельного объекта (одного цвета) и передача его на сервер,  а так же редактирование объекта и отображения в мире. 
В результате формирования данных 1 воксель занимает размер в 9 байт. После упаковки с помощью алгоритмов RLE и Morton (формирование массива цветов сохранено) - размер данных был уменьшен на тестовом файле с нескольких десятков Мб, до десятков кб ( условные 40мб превратил в 30-80 кб)
Проект немного отстал от текущей разработки, в дальнейшем будет обновлен (в процессе написания статья на habr).
В итоговом проекте была проведена оптимизация в мире, созданы пулы для мешей, для объектов, пере-использование мешей (если объект не меняется, то все инстансы и его копии держат одну сетку), пере-использование ресурсов для уменьшения разрастания хипа.
